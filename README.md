Nythera Bot Privacy Policy

This Privacy Policy explains how data is collected, used, and protected by Nythera Bot.

Nythera Bot is committed to protecting user privacy and ensuring transparency in data usage.

1. Data Collection
The bot may collect and store basic information such as:

Server IDs
User IDs
Channel IDs
Configuration settings
Command usage data

2. Purpose of Data
Collected data is used strictly to:

Provide automation features
Improve performance and reliability
Store server-specific configurations

3. Data Sharing
Nythera Bot does not sell, trade, or share user data with third parties.

4. Data Security
Reasonable measures are taken to protect stored data from unauthorized access, though no system is completely secure.

5. Data Retention
Data is stored only as long as necessary for functionality. Unused or unnecessary data may be removed periodically.

6. User Rights
Users may request data access or deletion by contacting the developer (Alverinael).

7. Updates to Policy
This Privacy Policy may be updated from time to time. Continued use of the bot means you accept any changes.
